# Vault Writers

This folder is the catalog of every system that writes content into this vault — connectors, agentic flows, scheduled skills, and any other vault-writing producer. Each registered writer has a `<writer-name>.md` writer-reference file declaring its frontmatter contract and its destination(s); the writer-reconciler pipeline reads those references to reconcile staged packets onto their destinations. This `_index.md` is MANDATORY — a positive override of the `_index` exemption list — and is regenerated by the librarian `writers-index-refresh` capability (operator narrative outside the sentinel markers is preserved).
